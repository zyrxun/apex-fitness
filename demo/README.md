# Apex Fitness — clickable demo

Open `demo/index.html` in any browser. One self-contained file: no build, no npm, no network requests.
Deliberately outside the npm workspaces so it never touches the app build.

Screens: Feed → run detail / strength detail (tap a card), Apex Score profile, Cohort & Friends leaderboards.
All athletes, activities, percentiles and ranks are fictional mock data for design review only.
